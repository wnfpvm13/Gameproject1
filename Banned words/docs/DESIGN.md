# 금칙어 게임 Korean 설계도

- 원본(살아있는 문서, 그림 포함): https://claude.ai/code/artifact/36208a40-0e2b-49e8-becf-d77f1b3fef31
- 이 파일은 2026-10-17 재검토 반영본의 사본이다. 내용이 다르면 원본이 우선이다.

## 게임 개요

**게임 이름:** 금칙어 게임 Korean

**한 줄 컨셉:** 자기 머리 위의 금칙어는 나만 못 보고, 마이크로 대화하다 그 단어를 입 밖에 내면 탈락하는 음성 파티 게임.

- **핵심 재미:** 남의 금칙어는 보이니까 대화를 유도해서 상대가 그 말을 하게 만드는 심리전. 예능 "금지어 게임"을 로블록스 보이스 챗으로 옮긴 형태.
- **플레이 인원:** 한 판 2~10명, 한 판 약 5~6분(버전1은 출제 45초 추가). 한국어 전용 서버(게임 언어·안내를 한국어로 설정). 음성 인식은 언어를 자동 감지해서, 다른 언어로만 말하면 한국어 금칙어에 안 걸리는 허점이 있다(안내 문구로 대응).
- **타깃:** 음성 채팅이 켜진 한국어 로블록스 플레이어(13세 이상, 연령 확인 완료). 친구끼리 들어오는 파티 플레이가 중심.
- **게임 모드:** 모두 "내 단어만 모르는" 예능형. 첫 출시는 버전1(직접 출제)·버전2(정해진 단어)만. 버전3·4는 테스트 후 업데이트 후보.

## 핵심 기술 판단

**가능하다.** 로블록스 공식 `AudioSpeechToText` API가 2026년 2월 정식 출시됐고, 2026년 5월부터 한국어를 자동 감지해 받아쓴다.

| 항목 | 내용 | 게임에 주는 영향 |
| --- | --- | --- |
| 연결 방식 | `AudioDeviceInput` → `Wire` → `AudioSpeechToText` | 클라이언트마다 자기 마이크에 수신기 연결 |
| 결과 값 | `Text`(인식된 문장), `VoiceDetected`(말하는 중인지, 복제 안 됨) | `Text`가 바뀔 때마다 서버로 전송 |
| 지연 시간 | 말이 끝난 뒤 대부분 0.5초 이내 | "말하고 잠깐 뒤 탈락" 연출로 충분 |
| 길이 제한 | 요청 1회당 오디오 최대 10초 | 문장 자동 분할이 손실 없는지는 1단계 확인 |
| 호출 한도 | 분당 1 + 5 × 동시접속자 | 10명이면 분당 51회. 증인까지 받아쓰면 2배 |
| 비용 | 기본 무료, 초과분은 Extended Services 유료 | 출시 초기에는 무료 범위로 설계 |
| 사용 자격 | 13세 이상 + 지역별 본인 인증 완료 | 인증 안 한 플레이어는 발화 감지 불가 |
| 키워드 가중치 | 지원 안 함 | 판정 로직으로 보완 |

주의할 점 4가지:

1. **오인식은 피할 수 없다.** "확정 → 바로 탈락"과 "의심 → '아슬아슬!' 경고만(탈락 없음)" 두 단계로 나눈다.
2. **받아쓰기는 클라이언트에서만 된다.** 로블록스 측 답변(2026년 5월)에 따르면 서버는 CPU 절약을 위해 오디오 처리가 거의 다 꺼져 있고, 공식 예제 코드도 클라이언트용으로 바뀌었다. 각 클라이언트가 자기 마이크를 받아써 서버로 보내고, 판정·탈락은 서버가 한다. 조작된 클라이언트는 금칙어 문장을 안 보낼 수 있어서 "증인 교차 확인"으로 막는다.
3. **스튜디오와 라이브 차이.** "스튜디오에선 되는데 라이브 서버에선 안 된다"는 제보가 있다. 1단계에서 라이브 서버 검증을 먼저 한다.
4. **호출 한도가 빠듯하다.** 탈락자는 받아쓰지 않고, 한도 초과나 인식 오류가 나면 "판정 일시 정지"를 띄워 그동안은 아무도 탈락시키지 않는다.

## 게임 규칙과 라운드 흐름

한 판은 **대기 30초 → 금칙어 배정 10초(버전1은 출제 45초 추가) → 대화 4분 → 결과 15초**. 숫자는 모두 조절할 초기값이다.

1. **대기:** 2명 이상이면 30초 카운트다운, 10명이 차면 바로 시작. 대기 중 모드 투표(인원에 안 맞는 모드는 목록에서 빠짐). 시작 직전 인원·모드를 다시 검사해 2명 미만이면 카운트다운 취소. 음성 인증이 없거나 서로 목소리가 안 들리는 플레이어는 관전석으로.
2. **금칙어 배정:** 모드에 따라 직접 출제하거나 단어장에서 뽑는다. 내 머리 위엔 `???`, 남의 머리 위에는 그 사람의 단어.
3. **대화:** 4분 동안 자유롭게 말한다.
4. **감지 = 탈락:** 목숨은 1개. 내 금칙어를 말하는 순간 "삐!"와 함께 의자에서 수영장으로 날아가 탈락.
5. **탈락 후:** 수영장에 떠서 계속 말할 수 있다. 탈락자 목소리는 받아쓰지 않는다(호출 한도 절약).
6. **승리:** 마지막 1명이 남으면 승리. 시간이 끝나면 1초 동안 들어오던 판정을 마저 처리한 뒤 생존자 전원 공동 승리. 마지막 두 명이 1초 안에 함께 탈락하면 무승부.
7. **순위:** 생존자가 위, 탈락자는 늦게 탈락한 순. 점수는 같은 순위끼리 가를 때만 쓴다.
8. **이탈·리셋:** 시작할 때 명단 고정. 도중에 나가면 탈락, 라운드 중 리셋 버튼 막음, 재입장은 그 판 관전.

- **유도 점수:** 누군가 탈락하기 직전에 마지막으로 말한 다른 플레이어 1명에게 +1점(탈락자도 받을 수 있음). 추임새로 점수를 쓸어 담지 못하게 1명에게만.
- **침묵 방지(필수):** 질문 카드 간격은 인원에 맞춰 4분 동안 모두가 최소 2번 받게 한다(10명이면 약 12초마다, 최소 10초). 10초 안에 두 어절 이상으로 답해야 하고, 직전 답과 같은 말이나 "네", "몰라" 같은 한 단어 답은 무효. 처음 놓치면 경고, 두 번째는 탈락. 오래 말이 없던 사람이 다음 카드 대상 1순위.

## 게임 모드

| 모드 | 인원 | 금칙어 정하는 법 | 재미 포인트 |
| --- | --- | --- | --- |
| 버전1 · 직접 출제 | 2~10명 | 각자 채팅으로 1개 제출 → 나를 뺀 무작위 1명에게 배정 | 친구끼리 가장 웃긴 판 |
| 버전2 · 정해진 단어 | 2~10명 | 서버가 단어장에서 배정 | 처음 온 사람도 바로, 오인식 가장 적음 |
| 버전3 · 누적 금칙어 (업데이트 후보) | 2~10명 | 단어장, 60초마다 각자 1개씩 추가(최대 4개) | 후반에 탈락이 몰림 |
| 버전4 · 팀 대항전 (업데이트 후보) | 4·6·8·10명 | 단어장, 2팀 | 상대팀 단어만 보이고 우리 팀 단어는 안 보임 |

### 버전1 · 직접 출제

1. **출제 45초:** 채팅으로 단어 1개 입력. 이 단계에서만 채팅이 남에게 보이지 않고 서버로만 간다(TextChatService 전달 차단이 되는지 1단계 확인, 안 되면 채팅창 자리에 같은 모양의 전용 입력창).
2. **검사:** 한글 2~6글자, 띄어쓰기 없음, 로블록스 필터 통과(`###`가 되면 반려), 중복 금지, 너무 흔한 말(네, 아니, 진짜, 근데 등) 반려.
3. **미제출:** 단어장에서 자동 출제.
4. **배정:** 누구도 자기 단어를 받지 않는 무작위 배치(교란 순열). 2명이면 맞바꿈.
5. **출제 점수:** 내 단어로 그 사람이 탈락하면 +2점. 이 모드의 점수 = 유도 점수 + 출제 점수.
6. **안내:** "흔한 단어일수록 마이크가 잘 알아들어요".

### 버전2 · 정해진 단어

- 카테고리: 음식, 동물, 학교, 물건, 장소, 날씨·계절. 한 판 안에서 섞어 힌트가 겹치지 않게.

### 버전3 · 누적 금칙어 (업데이트 후보)

- 시작 1개, 60초마다 각자 1개씩 추가(시작 1개 → 3분째 4개). 추가 순간 "새 금칙어!" 알림.

### 버전4 · 팀 대항전 (업데이트 후보)

- 4·6·8·10명(짝수)일 때만 투표 목록에 나온다. 2팀 자동 분배, 수영모 색으로 구분.
- 상대팀 단어만 보이고 우리 팀원 단어는 `???`. 서버는 팀전에서 우리 팀 단어를 아예 빼고 보낸다.
- 음성은 모두에게 들린다(팀 채널 없음).
- 상대팀 전멸 시 승리. 시간이 끝나면 생존자가 많은 팀 승리, 같으면 무승부.

## 맵: 수영장

**수영장 가장자리 의자에 둘러앉아 대화하다가, 금칙어를 말하면 의자가 튀어올라 수영장으로 날아간다.**

| 구역 | 내용 |
| --- | --- |
| 의자 링 | 수영장 가장자리에 의자 10개 원형 배치, 모두 중앙을 보고 앉음. 빈 의자는 숨김 |
| 수영장 | 탈락자가 떨어지는 곳. 튜브를 타고 떠다니며 계속 말할 수 있음 |
| 대기 구역 | 수영장 옆 매점·파라솔. 모드 투표와 마이크 테스트 |
| 관전석 | 음성 미인증 플레이어용 높은 심판석 |

탈락 연출(약 2초): 0초 "삐!" + 빨간 플래시 + 걸린 금칙어 표시 → 0.3초 의자 스프링, 포물선 비행 → 약 1.5초 착수 + 물보라 → 끝: 금칙어 공개, 튜브 생성.

구현 메모: 라운드 중 점프 차단 / 발사는 서버(착석 해제 → 다음 프레임에 중앙 방향 속도), 물은 Terrain Water / 수영장 안 목소리도 똑같이 들리도록 Audio API로 거리 감쇠 없는 연결(1단계 확인), 의자 링 지름 40스터드 안쪽.

## 시스템 아키텍처

**받아쓰기만 클라이언트가 하고, 판정·탈락·점수는 모두 서버가 한다.** 서버는 오디오 처리가 꺼져 있어서다. 내 금칙어는 내 클라이언트에 아예 보내지 않는다(`OthersWords`에 내 단어를 뺀 목록만, 팀전에서는 우리 팀 단어도 뺌, Attribute에 넣지 않음).

## 음성 감지 파이프라인과 금칙어 판정

확실하면 바로 탈락, 애매하면 "아슬아슬!" 경고만.

1. **받아쓰기(클라이언트):** 자기 마이크를 받아써 문장과 시각을 서버로(`Transcript`). 탈락자는 받아쓰지 않음.
2. **증인 교차 확인:** 생존자마다 다른 플레이어 1명을 증인으로 정하고(60초마다 교체), 증인 클라이언트도 그 사람 목소리를 받아써 보낸다. 다른 사람 목소리를 받아쓸 수 있는지는 1단계 확인 사항.
3. **정규화:** 어절 경계는 남긴 채 문장부호 제거, 영문 소문자화, 숫자 한글 표기 추가("3개" → "세개").
4. **확정 판정(바로 탈락):** 어떤 어절이 금칙어/변형으로 시작하고 나머지가 비었거나 조사·어미 목록이면 확정. 본인 문장에서 확정 → 바로 탈락. 증인 문장에서만 확정 → 본인이 같은 시각(±3초)에 문장을 아예 안 보냈을 때만 탈락, 본인 문장에 금칙어가 없으면 "아슬아슬!" + 불일치 기록(한 판 3회면 탈락, 기준은 1단계에서 조정).
5. **의심 판정(경고만):** 띄어쓰기를 지운 문장에서만 걸리거나, 3음절 이상 단어가 자모 편집 거리 1이면 "아슬아슬!"만. 의심으로는 탈락시키지 않는다(투표는 생존자·출제자 모두 이해관계가 있어 뺐다).
6. **판정 일시 정지:** 호출 한도 초과·받아쓰기 오류 시 아무도 탈락하지 않음.
7. **중복 방지:** 탈락 처리 시작 후 그 플레이어 문장 무시.
8. **억울해요 신고:** 결과 화면에서 오탈락 신고 → 판정 기록(걸린 단어, 시각)을 단어장 개선에 사용. 결과는 안 바꿈.

단어장 규칙: 2~4음절 명사 위주(1음절 제외), 자연스럽지만 너무 흔하지 않은 단어, 변형 목록 함께 저장(`{ word = "컴퓨터", aliases = {"컴퓨터", "computer", "컴표터"}, category = "물건", tier = "보통" }`), 욕설·민감 단어 금지, 3명 중 2명 이상 인식 실패 단어는 뺀다.

| 하단 중앙 | 내 상태 | 생존 여부, 마이크 상태, 점수 |
| 화면 중앙 | 질문 카드 | 질문 + 10초 게이지 |
| 화면 전체 | 감지 연출 | 플래시 + "삐!" + 걸린 금칙어 표시(전체 문장은 표시 안 함), 의자→수영장 |
| 화면 하단 바 | 아슬아슬 경고 | 의심 판정 때 "아슬아슬!" 1.5초(탈락 없음) |
| 결과 | 순위표 | 순위, 금칙어 공개, "가장 많이 남을 떨어뜨린 사람" |

## 안전·정책

**받아쓴 문장 전체를 남에게 보여주지 않는다.** 필터를 거쳐도 연령·차단·보호자 설정에 따른 소통 제한을 우회할 수 있어서, 화면에는 단어장/출제 검사를 통과한 금칙어만 띄운다.

| 주제 | 설계 |
| --- | --- |
| 문장 표시 | 받아쓴 문장은 남에게 표시 안 함. 감지 시 걸린 금칙어만. 마이크 테스트에서만 자기 문장을 본인에게 |
| 출제 단어 필터 | 버전1 단어는 `TextService` 필터 통과해야 표시 |
| 저장 | 들린 문장은 판정 후 버림. DataStore엔 점수·전적·억울해요 신고 기록만 |
| 사용 자격 | 음성 인증 필요. 같은 서버라도 서로 목소리가 안 들리는 조합이 있을 수 있어 1단계 확인, 안 들리면 관전 |
| 채팅 모드 | 만들지 않음(2026-10-17 결정). 음성 전용, 음성 자격이 없으면 관전만 |
| 음성 모더레이션 | 로블록스 기본 신고·제재 + 게임 내 음소거 버튼 |
| 개인정보 안내 | 첫 입장 때 받아쓰기 고지 |
| 마이크 끄기 악용 | 질문 카드에 10초 안에 받아쓴 문장이 안 오면 경고, 두 번째 탈락 |
| 조작 클라이언트 | 금칙어 문장을 숨길 수 있음 → 증인 교차 확인 + 불일치 누적 기록 |
| 단어장 안전 | 욕설·정치·종교·실존 인물·브랜드명 제외, 사람이 검토 |

## 구현 로드맵

1. **음성 인식 검증:** 클라이언트 `AudioSpeechToText`로 라이브 서버에서 3명이 단어 100개 → 인식률·지연·호출 한도. 통과: 인식률 80% 이상, 일반 대화 30분당 오탈락 1회 이하. 같이 확인: 다른 플레이어 목소리 받아쓰기(증인 전제), 정직한 플레이어의 본인·증인 불일치 빈도, 출제 채팅 숨김, 거리 감쇠 없는 음성, 음소거 상태 읽기, 서로 목소리가 안 들리는 조합.
2. **코어 루프:** 대기 → 배정 → 대화 → 확정 판정 → 탈락 → 결과. 회색 박스 수영장 맵.
3. **판정 고도화:** 조사·변형·자모 거리, 아슬아슬 경고, 증인 교차 확인, 판정 일시 정지.
4. **재미 장치:** 질문 카드, 유도 점수, 의자 발사·착수 연출, 수영장 튜브.
5. **출시 준비:** 단어장 300개, 전적 저장, 모바일 QA(Galaxy S23+ + 저사양 기기). 출시 모드는 버전1·2, 버전3·4는 출시 후 테스트 결과를 보고 업데이트.

## 1단계 1차 검증 결과 (2026-10-17, 스튜디오)

한국어 받아쓰기는 동작한다: 기계 음성 문장 60개 중 54개(90%)를 판정 규칙대로 잡았고, 말이 끝난 뒤 평균 0.76초(최대 0.81초). 사람 목소리 결과는 아직 없다. 자세한 내용과 재현법은 `tools/stt_probe/README.md`.

- 필수 설정: `VoiceChatService.UseAudioApi = Enabled`("자동"이면 빈 결과만), 게시 + 음성 채팅 활성화.
- 오인식: 기린→길이, 시계→시기(2음절 단어는 단어장 넣기 전 인식 검사).
- 빈 결과: "~는 어디 있어?" 20개 중 4개. 빈 결과는 "판정 없음".
- 단어만 단독으로 말하면 언어 감지가 틀림(코끼리→小キリ, 칠판→7판) → 숫자는 한자어 읽기로 되돌리고, 질문 카드는 두 어절 이상 요구.
- 영어로 말하면 한국어로 번역돼 나옴 → 다른 언어로 피하는 허점은 일부 막히지만 번역 오류로 오탈락 가능.
- 같은 문장이 두 번 오기도 함 → 2초 안 같은 문장은 하나로.
- 로블록스 음성 합성은 한국어 불가(InvalidText).
- 미확인: 사람 목소리, 실제 서버, 다른 플레이어 목소리 받아쓰기(증인 방식), 호출 한도.

결정됨: 예능형, 목숨 1개, 2~10명 한국어 전용, 폴더 `Banned words/`, 수영장 맵, 첫 출시는 버전1·2만(3·4는 테스트 후 업데이트), 게임 이름 "금칙어 게임 Korean".
