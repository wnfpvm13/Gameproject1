## 1. 게임 이름 — 정함: **의자에서 살아남기!** (오너 2026-10-26)

후보에 없던 이름을 오너가 직접 정했다. 작성자가 한 일(같은 날):
- 로고: `tools/art/make_logos.py`가 같은 스티커 그림(이름 두 줄 + 튀어 오르는 의자)을 면 모양별로 그린다. Decal은 그림을 면 전체에 늘려 붙이므로, 16:9 한 장을 쓰면 LED 화면(28.6×10.8, 2.65:1)에서 글자가 납작해졌다.
  - `logo.png` 1024×576: 스토어·홍보용(올리지 않음).
  - `logo_screen.png` 1024×387 → `rbxassetid://81598731615102`: 뒤쪽 LED 화면(`IMAGES.screenLogo`).
  - `logo_podium.png` 1024×465 → `rbxassetid://74923008573479`: 진행자 단상 앞면(`IMAGES.podiumLogo`, 전에는 화면과 같은 그림).
  - 올린 방법: Studio MCP `upload_image`(로컬 http 서버). Studio에서 로드 성공 확인, 캡처로 늘어짐 없음 확인.
- 스토어 아이콘 시안: 같은 생성기의 `icon.png` 512×512(의자 + "펑!", 작게 보여도 읽히게 이름은 뺌). 아이콘은 Creator Dashboard에서 오너가 올린다.
- 맵 반영: `tools/build_pool_hall.luau`의 `IMAGES`. QA 장소에는 두 Decal만 바꿔 확인했다(저장 안 함). 게시 장소에는 아래 2번 순서대로 맵을 다시 지으면 들어간다.
- 같은 이름 확인: 웹 검색에서는 같은 이름의 Roblox 게임을 찾지 못했다(2026-10-26). Roblox 안 검색은 웹 검색으로 대신할 수 없으므로 오너가 Roblox에서 한 번 검색해 본다(확인 필요).
- 게임 안 글자에는 이름이 나오지 않는다(`Config.TEXT`에 게임 이름 없음). 이름이 보이는 곳은 로고 그림과 스토어뿐이다.

고르기 전의 후보(기록):

## 2. 장소·경험 설정 (오너, Creator Dashboard / Studio)

- [ ] **게시자 자격·대상 연령:** Roblox는 공개와 업데이트 모두에 게시 요건(계정 상태, 연령 확인 등)을 적용하고 대상 연령에 따라 요건이 더 붙는다(https://create.roblox.com/docs/production/publishing/publish-games-and-places — 실제 충족 여부는 오너 계정에서 확인 필요). 대상은 설계상 17세 전후(음성 채팅 13세 이상 연령 확인).

- [ ] 게시 장소: 시험 장소 84102094280848(설치기 경로). Studio에서 `tools/build_pool_hall.luau` → `tools/build_pool_lighting.luau` → `tools/install_game.luau`(Edit에서 실행, "game installed").
- [ ] `TextChatService.ChatVersion = TextChatService`, `StarterGui.ScreenOrientation = LandscapeSensor`(설치기는 바꾸지 않음).
- [ ] Communication: 음성 채팅 켜기, **"Chat & Voice Groups APIs" 켜기**(진행자 조건 확인에 필요), **Platform Integrated Chat 꺼짐 확인**(켜져 있으면 스무고개 채팅 규칙·채팅 참가가 안 됨; Roblox가 2027년 2월에 자동으로 켬).
- [ ] 최대 인원: 의자 10 + 진행자 + 관전 몇 명 → **12** 권장(10명을 넘는 사람은 그 판 내내 관전).
- [ ] 성숙도 설문: 실제 내용대로 답한다 — 실패하면 폭발로 의자에서 날아감(피·부상·죽음 없음), 음성 채팅이 필수, 주된 활동은 미니게임(퀴즈·반응 게임). 분류 결과는 Roblox가 정한다.
- [ ] 공개 여부·비공개 서버(선택): 친구끼리 하는 게임이라 비공개 서버를 켜면 좋다(공개 뒤에 켤 수 있음).
- [ ] 원본 언어 = 한국어, 자동 번역 확인: 코드가 `AutoLocalize`를 끄지 않으므로 원본 언어가 한국어가 아니면 UI·문제·초성 글자가 번역되며 깨질 수 있다(확인 필요).
- [ ] 지원 기기: 음성이 필수라 콘솔·VR을 받을지 정한다(가로 화면 고정, PC·폰·태블릿 기준으로 만듦).
- [ ] 채팅 연령 확인: Roblox가 채팅에도 연령 확인을 넓혔다면 "말 대신 채팅으로 참가"와 스무고개 채팅에 영향이 있다(확인 필요 — 라이브 확인 항목에서 본다).

## 3. 스토어 자료 (초안 — 오너가 고쳐 씀)

**제목:** `[음성] 의자에서 살아남기!`

**설명(초안):**
> 미션에 실패하면 의자가 펑! 수영장으로 날아가요.
> 퀴즈, 눈치 게임, 폭탄 돌리기, 총잡이 결투, 머리 위 스무고개 같은 미니게임 17가지 중 6개를 이어서 하고, 목숨 3개를 지켜 결승 퀴즈에서 살아남으세요. 진행자를 맡아 다음 게임을 직접 고를 수도 있어요.
> 최대 10명 · 음성 채팅을 켠 계정만 참가할 수 있어요(말하기가 어려우면 '말 대신 채팅으로 참가').

**아이콘:** 로고의 튀어 오르는 의자 + "펑!" 스티커만 크게(작은 크기에서도 읽히게). 시안은 `.qa/logos/icon.png`(`tools/art/make_logos.py`로 다시 만들 수 있음), 오너가 고쳐 쓰거나 그대로 올린다.

**썸네일 3안(Studio 화면 + 스티커 글씨):**
1. 의자 줄 가운데가 크게 폭발하고 아바타가 수영장 쪽으로 날아감, 옆 사람들 반응 — "실패하면 펑!"
2. 연쇄 폭발: 의자 3개가 차례로 터짐, 가장자리에 벨·폭탄·총·악어 스티커, 구석에 "비행왕 32.4m"
3. 긴장 직전: 폭탄 넘기기 카드와 무궁화 빨간불, "누가 날아갈까?"

## 4. 라이브 확인 (오너 + 작성자, 게시 직후 비공개로)

- [ ] 마이크 확인: 음성 계정이 "마이크 체크!"를 통과해 "준비 완료"가 되는지(받아쓰기가 라이브에서 안 되면 아무도 준비가 안 됨 — `REQUIRE_VOICE_READY`).
- [ ] 2~4명 한 판: 투표·브리핑·미션·결승·우승 연출, 효과음 크기(음성보다 작게, `SOUND_VOLUME` 0.5).
- [ ] 머리 위 스무고개: 남의 단어를 쓴 줄이 그 주인에게 안 보이는지, 쓴 사람이 날아가는지(Studio에서는 다른 클라이언트로 채팅이 안 와서 확인 못 함).

- [ ] 채팅 참가자(음성 계정·채팅)의 채팅이 다른 참가자에게 보이는지(채팅 연령 확인 영향).
- [ ] 진행자 조건(음성 그룹·채팅 도달·친구 제외)과 진행자 화면.
- [ ] 폰(Galaxy S23+)과 저사양 안드로이드 한 판: 카드·투표 행·머리 위 단어가 읽히는지, 프레임.
- [ ] 서버 콘솔에 우리 오류 없음.
