# 프로토타입 v0 — 수영장 의자 + 금칙어 탈락 (2026-10-17)

## 변경: 일렬 패널석 + 정면 카메라 (오너 요청 2026-10-17)

둘러앉는 타원(최대 68스터드)은 대화하기에 멀어서, 의자를 수영장 북쪽 가장자리에 **한 줄로**(5스터드 간격, 끝에서 끝 45스터드) 놓고
라운드 중엔 모든 클라이언트 카메라를 수영장 위 정면(`PoolMap.ShowCamera`, FOV 55)에 고정했다(`src/client/ShowCamera.luau`).
가운데 의자부터 채움(5,6,4,7,…). 탈락은 자기 의자 앞 수영장으로 발사. 말풍선은 스터드 단위(4.4×1.3)라 옆 사람과 안 겹침.
확인: 3인 테스트에서 셋 다 화면 안 같은 높이, 1인은 Chair05(화면 중앙 884,436 / 1921×911), 착수 지점 (-0.5, -6.6, -1.0).

## 들어간 것 (첫 버전)

- 맵(`tools/build_pool_map.luau`, Edit에서 실행): 데크 120×90, 수영장 44×28(지형 물, 수면 y = -1.5),
  타원(34×24) 위 의자 10개(수영장 중앙을 봄), 파라솔 4개, 투명 울타리, 북쪽 스폰.
- 라운드(`src/server/RoundService.luau`): 대기 → 카운트다운 15초 → 배정 6초 → 대화 240초 → 결과 8초.
  최소 인원 라이브 2명 / 스튜디오 1명(`src/shared/Config.luau`). 참가자 명단은 시작 때 고정, 나가거나 죽으면 탈락.
- 의자(`src/server/SeatService.luau`): 배정된 사람만 앉을 수 있고, 라운드 중 일어나면 다시 앉힘. 점프 높이 0 + 클라이언트에서 점프·리셋 막음.
- 판정: 각 클라이언트가 자기 마이크를 받아써(`src/client/Speech.luau`) `Transcript`로 보내면 서버가 `Judge.classify`로 판정.
  확정이면 탈락, 의심이면 "아슬아슬!" 알림만.
- 탈락: 의자 고정(SeatWeld) 제거 → 한 프레임 뒤 수영장 중앙으로 포물선 발사(최고 약 35스터드, 1.2초 비행) → 1.3초 뒤 사망 → 스폰에서 부활(관전).
- 화면: 상단 진행판(단계·남은 시간·생존 수), 음성 연결 안내, 탈락/아슬아슬 알림, 머리 위 말풍선(남은 단어, 나는 `???`, 결과 때 모두 공개).
- 단어장: 버전2 정해진 단어 57개(`src/server/WordBank.luau`), 카테고리 분산 추첨.

## 변경: 거리 상관없는 음성 (오너 결정 2026-10-17)

기본 음성은 캐릭터 안 `AudioEmitter`(서버 생성)에 7~80스터드 2차 감쇠가 걸려 있다. 서버(`src/server/VoiceService.luau`)와
클라이언트(`src/client/FlatVoice.luau`) 양쪽에서 곡선을 `{0 = 1, 2000 = 1}`로 바꿨다.
확인(실계정 1인): 곡선 `{0=1,2000=1}`, 120스터드 떨어진 리스너 기준 audibility 1.
스튜디오 다인 테스트 계정(Player1~3)은 음성 자격이 없어 Emitter가 안 생기므로 다인 확인은 실제 서버에서 해야 함.

## 추가: 토크쇼(게스트) 모드 + 모드 투표 (2026-10-17)

KBS 위험한 초대 방식. 카운트다운 중 "클래식 / 토크쇼(3명+)" 투표(동률은 무작위, 3명 미만이면 클래식).
- 게스트 1명(게스트를 가장 적게 한 사람)이 수영장 뗏목 의자(`PoolMap.GuestRaft.GuestSeat`, 패널을 마주봄)에 앉는다.
  게스트는 금칙어가 없고 아무 단어도 못 본다(패널 말풍선이 "?"). 모두에게 게스트 말풍선은 "게스트".
- 게스트가 패널의 금칙어를 말하면 그 패널이 날아감(한 문장에 여러 개면 동시에). 게스트 +1/명, 직전 힌트 준 패널은 유도 +1.
- 패널: 자기 금칙어를 말하면 탈락, **남의 금칙어를 직접 말하면 반칙(본인 탈락)** → 힌트로만 유도.
- 질문 카드는 패널만. 게스트가 나가면 그 판은 끝.
- 확인(로컬 3인): 투표 → 토크쇼, Player1 게스트(뗏목), 패널은 상대 단어·내 ???·"게스트" 보임, 게스트는 "?"만;
  게스트 "나는 바다에서 피자 먹는 게 좋아" → 두 패널 동시 탈락 → "모두 탈락! · 게스트 Player1 2명 날림", 게스트 점수 2;
  다음 판 게스트 Player3로 교대, 패널 Player2가 "게스트님 김밥 좋아해요?"(Player1의 단어) → 반칙 탈락.
