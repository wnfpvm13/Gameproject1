## 사실 확인 (Claude)

- STT 기본 한도: 경험 전체 분당 `1 + 5×CCU` 요청, 초과분 $1/100만 요청 (Creator Hub Extended Services). 요청 1건 = 최대 10초 오디오(DevForum 정식 출시 글). 한도 초과 시 동작은 문서에 없음.
- 반향: 정식 출시 글에 "에코 캔슬링 개선, 대부분 플랫폼 적용, Windows·iOS는 곧" — 현재 적용 여부 미확인. Roblox는 STT용으로 헤드폰 + 푸시투토크 권장.
- 지연: Roblox 측정 "발화 종료 후 대부분 0.5초 미만".
- 버전1(직접 출제)은 아직 미구현(`PROTOTYPE_v0.md` 남은 작업 목록). 현재 모드는 클래식(단어장 = 버전2) + 토크쇼.

## 우리 게임에 맞지 않는 주장

- 턴제 → 자유 대화 개편: 이미 자유 대화형(모든 생존자 발언 판정).
- 합성어·활용형(사과나무·사과했어·청사과)도 탈락이 "사용자 확정": 보고서가 본 다른 설계서의 조건. 우리 판정(어절 시작 + 조사·서술격 어미만 탈락, 나머지는 "아슬아슬")이 목숨 1개·자동 STT에 더 안전 — 둘 다 현행 유지 권장.
- 인원별 5~10분: 오너 확정 3분과 충돌.
- 유령 아바타: 유령 삭제 결정과 충돌.
- 원형 라운지: 수영장·의자 일렬 결정과 충돌.
- 50인 서버·동시 5경기: 현재 구조(서버당 1판, 최대 10명)의 전제가 아님.
- 누적 금칙어 1→2→3: 후속 업데이트(버전3) 실험으로는 타당. 3분에 맞추면 약 60초·120초에 추가.

## 오너에게 물을 것

1. 질문 카드 무응답 탈락 — 권장: 첫 친구 테스트는 경고만.
2. 합성어·활용형 — 권장: 현행(아슬아슬만) 유지. 보고서의 "사용자 확정"이 오너 본인의 결정인지 확인 필요.
3. 반향 대책 — 권장: 첫 테스트는 이어폰 권장 안내, 스피커 환경 지원은 시험 결과로 결정.
4. 다음 작업 — 권장: 버전1(직접 출제) 구현 → 실기기 반향·인식 테스트.

## 실기기로만 확인 가능

- 반향: A는 마이크 켜고 침묵, B가 A의 금칙어 반복. A의 헤드셋/내장 스피커/외장 스피커 × PC/폰으로 A 전사·탈락 기록.
- 한국어 판정 품질: 단어 포함/미포함 문장, 합성어, 빠른 말·웃음·소음 → 미탐·오탐(한 판당 억울한 탈락률).
- 동시 발언 2→4→10명, 헤드셋/스피커 분리 비교.
- 경계: 대화 시작 직전·카드 종료 직전·3분 종료 직전 발언.
- STT 요청량: CCU 2·4·10에서 로비·관전 STT 켬/끔 비교.
- 장애 복구: 음성 끊기·네트워크 전환·앱 백그라운드 중 카드가 탈락으로 바뀌지 않는지.
- 휴대폰에서 양 끝 의자 단어·이름·질문 가독성.
