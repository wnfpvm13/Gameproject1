# V3 판 규칙 — 만든 기록 (2026-10-22~23, 1단계 묶음 2b)

후임 에이전트용 기록이다. 규칙은 `docs/DESIGN_V3.md` 2번(흐름)·4번(목숨)·13번(구조)이 기준이고, 여기에는 어떻게 만들었고 무엇을 시험했는지 적는다. 발사 연출(묶음 2a)은 `docs/FLING_2026-10-22.md`.

## 무엇이 들어갔나

V2 규칙(자유 대화·누적 금칙어·받아쓰기 판정·대화 카드·투표)을 걷어내고 V3 판 흐름을 넣었다.

- **흐름:** 대기실 → 카운트다운 → 배정(의자, 목숨 3개) → 본 경기 8분(자유 대화 40초 → 미션 → 발사 → 자유 대화 …) → 결승(서든데스) → 결과 → 빠른 재경기.
- **목숨:** 실패하면 목숨 -1과 발사, 5초 뒤 제자리. 0이면 탈락하고 비행이 끝난 뒤 관람석. 한 사건에 벌칙 1번(날아가는 동안 온 사건도 그 사람에게는 소진), 날아가는 동안 벌칙 없음, 동시 실패는 한꺼번에.
- **전멸:** 본 경기에서 남은 사람이 한꺼번에 떨어지면 아무도 탈락시키지 않고(목숨 0인 채로) 그 사람들끼리 결승.
- **결승 시점:** 8분이 지나면, 또는 4명 이상으로 시작한 판에서 3명 이하가 남으면 바로. 시작 인원은 본 경기가 시작될 때 남은 사람 수다(배정 중 나간 사람은 빼고). 결승 첫 문제는 진행 중인 발사가 끝난 뒤.
- **결승:** 틀린 사람은 바로 탈락, 모두 틀리면 아무도 탈락하지 않음, 90초 상한(그 전에 시작한 문제는 끝까지) → 남은 사람 공동 우승. 1명만 남으면 결승 없이 우승.
- **판이 정해지면 미션 취소:** 본 경기에서 1명만 남거나, 전멸 → 결승이 정해지거나, 4명 이상으로 시작한 판에서 3명 이하가 남으면, 결승에서 1명만 남으면, 진행 중인 미션은 바로 멈추고 그 뒤에 오는 실패는 버린다(설계 2번 "확정 뒤에 도착한 결과는 버린다"). 8분이 지나는 것은 취소가 아니다.
- **시간 예산:** 남은 시간에 "미션 예상 길이 + 발사 5초"가 안 들어가면 새 미션을 시작하지 않고 자유 대화로 채운다. 8분이 될 때 진행 중인 미션은 끝까지 한다. 발사 중인 사람이 있으면 미션은 착지·복귀 뒤에 시작하고, 그때까지 아무도 착지하지 못하면(최대 18초) 그 미션은 건너뛰고 자유 대화를 한 번 더 한다.
- **그 밖:** 퇴장 = 탈락. 판 중 캐릭터가 새로 생기면(떨어짐 등) 목숨을 깎지 않고 다시 앉힌다. 서버 종류(공개·비공개)를 판마다 정한다(Studio는 설정값과 `workspace` 속성 `BW_ServerKind`).
- **아직 없는 것:** 금칙어(묶음 5), 진행자(묶음 3), 실제 미션(묶음 4), 음성·채팅 참가 선택과 채팅 말풍선 강조(묶음 2c). 미션은 Studio 전용 시험 미션 하나뿐이라 **라이브 서버는 미션 없이 이야기만 하다가, 8분이 지나거나 퇴장으로 판이 정해지면 남은 사람이 결승 없이 우승**한다(게시 장소는 바꾸지 않았다).

## 작성자가 정한 기본값 (설계에 없던 것, 오너가 바꿀 수 있음)

- 결승 상한 전에 시작한 문제는 상한을 넘겨도 끝까지 한다(본 경기 미션과 같은 규칙). 결승 문제가 오류를 내면 결승을 끝내고 남은 사람이 공동 우승한다.
- 본 경기 미션은 발사 중인 사람이 착지·복귀한 뒤 시작한다(날아가는 동안 문제를 못 보는 일을 줄임). 18초 안에 모두 착지하지 못하면 그 미션은 건너뛴다.
- 미션의 사건 번호: 미션은 사건 이름(`key`)만 주고 RoundService가 "미션 실행 번호 + 이름"으로 판 전체에서 유일하게 만든다.
- 목숨 알림은 사건 하나에 한 번: "A, B 목숨 -1", "C 탈락!", 내가 맞았으면 맨 위에 "내 목숨 -1 · 남은 목숨 n" 또는 "탈락! 관람석에서 응원해 주세요", 전멸이면 마지막 줄에 "남은 사람이 한꺼번에 떨어져서 그대로 결승으로 가요". 누군가 탈락하면 부저와 붉은 번쩍임. 판 중에 들어온 사람에게는 "본 경기 시작!" 같은 단계 알림을 띄우지 않는다.
- 고정 문구에 단어장 단어를 넣지 않는다: "의자가 날려 보내요" → "날아가요", "본 게임" → "본 경기"(HUD 단계 이름도), "시험 미션" → "연습 미션".
- Studio 혼자 시험: 마지막 목숨에서 실패하면 "전멸 → 결승" 규칙에 걸리고, 결승은 2명 이상이어야 해서 바로 우승으로 끝난다.
- Studio 시험 키(`DevFling`)는 본 경기의 자유 대화 중에만 받는다(미션 중·발사 대기 중·판이 정해진 뒤에는 무시). 그래서 시험 키로는 미션과 겹치는 발사를 만들 수 없다.
- 받아쓰기 불안정 알림은 마이크 테스트 중에만 띄운다(판 중에는 받아쓰기를 끈다).

## 시험한 방법

- **가상 시계 시험**(`python -I tools/tests/run_tests.py`): 새 묶음 `round`(58개). 실제 `LifeService`·`Timeline`·`MissionRunner`·`RoundService` 소스에 가짜 의자·관람석·음성·점수와 대본대로 실패시키는 미션을 붙여 판 전체를 돌린다.
    - LifeService 18개: 한 사건 1번, 비행 중 면제와 그 사건 소진, 마지막 목숨, 전멸 → 결승, 동시 실패, 날아가는 생존자, 주관 판정 한도(공개·비공개), 새 판 초기화, 즉시 탈락, 잠수(비행 중 놓친 것 제외).
    - Timeline 5개. 판 전체 35개: 시간 예산(다음 미션이 안 들어가면 시작 안 함, 기대 횟수는 Config로 계산), 8분 → 결승, 결승 상한 → 공동 우승과 점수(마지막 문제는 상한을 넘겨 끝남), 5명 중 3명 남음 → 비행 뒤 바로 결승(비공개 서버 설정), 결승 오답 탈락·모두 오답, 2명 전멸 → 둘이 결승(같은 미션의 두 번째 사건은 버림), 1명 남음 → 결승 없이 우승(결과는 비행 뒤), 퇴장 = 탈락, 미션 도중 퇴장 → 미션 취소·결과 버림(2명 판, 5명 → 3명 판), 결승 문제 도중 상대 퇴장 → 바로 우승, 결승 문제 오류 → 결승 끝, Studio 시험 신호(미션 중에는 무시), 오래된 판·바뀐 캐릭터의 복귀 신호 무시, 판 오류 없음.
    - `server` 묶음에 고정 문구 검사를 넣었다: `Config.TEXT`가 단어장 단어를 포함하면 실패한다(`tools/check_content.luau`와 같은 규칙, Studio 없이). 처음 돌렸을 때 위 세 문구가 걸려서 고쳤다.
    - 헛통과 확인: 규칙 여섯 곳(전멸 → 결승, 3명 이하 결승, 판이 정해지면 미션 취소, 결승 문제 오류 → 결승 끝, 3명 이하가 되면 미션 취소, 시험 키는 자유 대화 중에만)을 하나씩 일부러 깨 보고 해당 시험이 실패하는 것을 확인한 뒤 되돌렸다.
- **정적 검사**(`python -I tools/lint/run_lint.py`): 새 문제 0건. 고치거나 지운 파일에서 사라진 기존 경고 6건을 목록에서 뺐다(`--update-known`, 새로 받아들인 경고는 없음).
- **의존 방향**: 31개 모듈, 57개 require, 층 규칙·순환 없음(missions 층은 MissionRunner만 require).
- **Studio**(`.qa/v3_fling.rbxlx`, `tools/install_game.luau`를 Edit에서 실행): 장소 사본의 Config만 짧게 바꿨다(카운트다운 5, 배정 4, 결과 8, 본 경기 75, 자유 대화 8, 결승 30, 시험 미션 5초; 저장소에는 넣지 않음). 클라이언트에 리모트 기록기를 붙이고 서버에서 캐릭터 위치를 기록했다.
    - 확인: 자유 대화 8초 → 시험 미션 5초 반복, 미션 실패 → 목숨 -1·발사·물보라·5초 뒤 자기 의자, F 키(`DevFling`)로 목숨 -1, `"out"` → 비행 뒤 관람석(점프 7.2, 소유권 플레이어), 마지막 목숨 실패 → 전멸 알림 → 결과 "우승!", 탈락 → "우승자 없이 끝났어요", 다음 판에 목숨 3개로 다시 시작, 콘솔 오류 없음.
    - 이때 고친 것 2개: 발사 중에 미션이 시작되던 것(이제 복귀 뒤 시작, Studio에서 F를 미션 2초 전에 눌러 확인), 판이 끝나기 직전 "자유롭게 이야기하세요"가 한 번 깜빡이던 것.
    - HUD(본 게임 · 자유롭게 이야기하세요 / 1:00 / 내 목숨 ♥♥♥ / 생존 1 / 1, 문구를 바꾸기 전)는 캡처로 봤다. 처음에는 Studio 창이 최소화돼 있어 3D 화면이 흰색으로만 찍혔다.

## 교차검증 (Codex 1번 + Claude 검토자 1번)

- **Codex**(gpt-6.1-sol xhigh): 이번에도 로컬 파일 읽기가 도구 오류로 실패해 붙여 준 diff만 보고 판단했다. P1 1건·P2 2건·P3 1건.
    - P1: 미션 도중 퇴장으로 승자가 정해져도 미션이 끝까지 돌아 승자가 벌칙·발사를 받을 수 있음.
    - P2: 결승 미션 오류가 대기 없는 반복으로 이어짐. P2: 비행 대기 상한(6초)이 지나면 새 발사가 남아 있어도 다음 미션 시작.
    - P3: 탈락자 말풍선의 튐이 다음 상태 방송에서 바로 지워짐.
- **Claude 검토자**(새 에이전트, 시험·정적 검사를 직접 다시 돌림): P1 없음, P2 2건, P3 여러 건.

    - P3: 라이브 동작 설명이 실제와 다름(퇴장으로 판이 일찍 끝남), 탈락자 말풍선 연출(Codex와 같음), 전멸 알림이 목숨 알림을 덮어씀·결승에서 혼자 남았을 때 "모두 틀려서" 알림·늦게 온 사람의 "시작" 알림, 고정 문구 3개가 단어장 단어 포함, 잠수에 비행 면제 없음·건너뛴 사람에게 같은 사건이 다시 오면 벌칙, 시험 하나가 항상 참(서버 종류)·숫자가 Config에 묶임·빠진 장면, 문서 잔여(경고 6건 설명, 층 표 위치, Speech 주석, TestMission의 ctx 타입 복사), Studio 시험 키가 판이 정해진 뒤에도 먹힘, 오류 복구 때 판 번호를 안 올림.
- **판단과 반영:** 근거를 모두 코드에서 확인했고, 심각도는 Codex의 P1을 P2로 봤다(승자는 그대로 이기지만 불필요한 벌칙·발사·지연이 생김). 아래처럼 전부 고쳤다.
    - 판이 정해지면 미션 취소(`cancelled`), 취소 뒤 `fail`·`show` 버림, 취소되면 바로 깨는 `ctx.wait`. 결승도 1명만 남으면 바로 끝.
    - `MissionRunner.run`이 성공 여부를 돌려주고 결승 문제가 오류를 내면 결승 끝, 결승 반복마다 최소 한 번 양보.
    - 비행 대기는 "모두 착지할 때까지, 최대 18초"로 바꿈. Studio 시험 키는 본 경기가 진행 중일 때만.
    - 전멸 알림은 `LifeLost`의 `final`로 같은 알림에 합침. 결승에서 1명만 남으면 "모두 틀려서" 없이 끝. 늦게 온 사람에게 단계 알림 없음.
    - 탈락자 말풍선은 하트를 바로 0으로 바꾸고 튐이 끝난 뒤 사라짐.
    - 고정 문구 3개 교체 + 자동 검사(`server` 시험 4).
    - LifeService: 날아가는 동안 온 사건도 그 사람에게 소진, 비행 중 놓친 응답은 잠수로 안 셈.
    - 시작 인원은 본 경기 시작 때 남은 사람 수(배정 중 퇴장자 제외). 오류 복구 때 판 번호를 올려 남은 ctx를 취소.
    - 시험 보강(위 "시험한 방법"), 문서·주석 정리.
    - 남긴 것(P3): TestMission이 미션 ctx 타입을 복사해 둔 것. 미션은 서비스를 require할 수 없어 공용 타입을 둘 곳이 마땅치 않다. 미션이 늘어나는 묶음 4에서 정한다.
- **Codex 재확인(1번):** 지난 지적 1·2·4는 고쳐짐, 3·5는 일부. 남은 것은 P2 2건과 P3 2건이었다.
    - P2: 4명 이상 시작한 판의 "3명 이하 → 바로 결승"이 미션 취소 조건에 없음. 미션 도중 퇴장으로 3명이 되면 미션이 끝까지 돌아 결승 진출자가 목숨을 잃을 수 있다.
    - P2: 비행 대기 상한(18초)이 지나면 비행이 남아도 미션 시작. 대기·전환 중에도 시험 키를 받음.
    - P3: 탈락자 말풍선 유지가 끝날 때 결과 화면의 리스폰한 캐릭터 말풍선을 다시 그리지 않음. P3: TestMission의 ctx 타입 복사(그대로 둠).
    - 고친 것: `Timeline.fewLeft`를 따로 두고 본 경기 취소 조건(`mainSettled`)에 넣음. `waitFlights`가 모두 착지했는지 돌려주고, 못 했으면 미션을 건너뜀. 시험 키는 자유 대화 중에만. 말풍선 유지가 끝나면 마지막 화면을 다시 그림. 시험 2개 추가(미션 도중 5명 → 3명이면 바로 결승·결과 버림, 미션 중 시험 키 무시), 각각 해당 코드를 일부러 되돌려 실패하는 것을 확인.
    - 규칙대로 재확인은 더 받지 않았다. 재확인 뒤 고친 부분은 시험·정적 검사·Studio 혼자 시험으로만 확인했다.

## Studio 시험 요령 (이번에 쓴 것)

- 설치: `python -I tools/install_game.py` 뒤, 143KB라 MCP 도구에 직접 넣지 말고 `moncook-claude/MonCook/tools/studio_mcp_client.py call execute_luau '{"studio_id":..., "datamodel_type":"Edit"}' tools/install_game.luau`로 파일째 보낸다. 설치기는 기존 폴더를 지우고 다시 만들므로 장소 Config에 넣은 짧은 타이머도 다시 넣어야 한다.
- 시험 신호: 클라이언트에서 `Remotes.DevFling:FireServer()`(목숨 -1), `("out")`(바로 탈락), `("show")`(목숨은 그대로 발사만). 본 경기의 자유 대화 중에만 받는다.
- 기다리기는 서버 데이터모델에서 `task.wait`로 한다. 클라이언트에서 오래 기다리면 MCP가 호출 뒤 카메라 종류를 되돌려 쇼 카메라가 풀린다.
