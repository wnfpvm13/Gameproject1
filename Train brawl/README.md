# Train brawl (기차 난투, 가제)

MonCook, 금칙어 게임, Western train(지붕 위 오비)과 별개인 로블록스 게임. 나란히 달리는 큰 기차들 지붕 위에서 맨주먹과
상자로 떨어지는 무기로 서로를 때려 떨어뜨린다. 기차 아래로 떨어지면 기차를 놓쳐 탈락, 마지막 1명이 이긴다. 설계와 결정 기록:
[docs/DESIGN.md](docs/DESIGN.md)

**지금 코드: 시제품 A + 체력·마우스 고정 + 장외홈런·사운드·조명 + 맵 구조 + 꾸미기 + 기차 1.5배 + 맨주먹과 줍는 무기 + 화면 글자·소리 다듬기(5a) + 전신 자세와 연타(5b) + 타격감(5c) + 표시·지붕(5d)** ([docs/PROTOTYPE_A_2026-10-24.md](docs/PROTOTYPE_A_2026-10-24.md),
[docs/HEALTH_AIM_2026-10-25.md](docs/HEALTH_AIM_2026-10-25.md), [docs/HOMERUN_SOUND_2026-10-25.md](docs/HOMERUN_SOUND_2026-10-25.md),
[docs/MAP_GRAYBOX_2026-10-25.md](docs/MAP_GRAYBOX_2026-10-25.md), [docs/DECOR_2026-10-25.md](docs/DECOR_2026-10-25.md),
[docs/SCALE_UP_2026-10-25.md](docs/SCALE_UP_2026-10-25.md), [docs/WEAPONS_2026-10-25.md](docs/WEAPONS_2026-10-25.md),
[docs/FEEL_5A_2026-10-26.md](docs/FEEL_5A_2026-10-26.md), [docs/FEEL_5B_2026-10-26.md](docs/FEEL_5B_2026-10-26.md), [docs/FEEL_5C_2026-10-26.md](docs/FEEL_5C_2026-10-26.md), [docs/FEEL_5D_2026-10-26.md](docs/FEEL_5D_2026-10-26.md), 검토 뒤 고친 것 [docs/FEEL_REVIEW_2026-10-26.md](docs/FEEL_REVIEW_2026-10-26.md))
- 큰 기차 3대(지붕 폭 15, 한 대 길이 약 95~100)가 틈 15스터드를 두고 나란히 선다. 기차마다 4칸(기관차, 석탄차, 화물칸, 평판차, 승무원차 중)이고 앞뒤로 조금씩
  어긋나 서서 옆 기차와 마주 보는 칸이 다르다. 평판차는 낮은 바닥(상자 2개가 계단), 승무원차 위 전망대와 기관차 굴뚝 위가
  높은 곳이다. 기차는 제자리이고 모래·자갈 바닥, 침목·선인장·바위·전신주와 양옆 협곡이 뒤로 흐른다. 판자는 같은 높이의 평평한 지붕이 마주
  보는 곳에만 틈마다 2개(지금 4개). 틈은 점프로 못 건넌다(높이 차가 있어도, Studio 실측).
- 꾸미기: 칸마다 바퀴·연결기·문·사다리·창문·"CANYON LINE" 글씨, 기관차는 연결봉이 달리는 속도로 돌고 굴뚝에서 연기가 위로
  올라가 흩어진다. 협곡 벽(층층이 색이 다른 사암)이 양옆에 서고 끝은 대기 안개로 가린다. 관전석은 열기구 4개가 매단 모양에
  깃발을 둘렀고 유리 바닥으로 아래 기차가 보인다. 장식은 모두 화면마다 그리는 그림이라 부딪히지 않는다(굴뚝만 단단함, 그 위에 서면 연기가 멈춤).
- 기본은 맨주먹이다. 클릭(모바일 "때리기" 버튼, 게임패드 R2)하면 주먹을 앞으로 지른다. 난투 중에 낙하산 상자가 지붕에
  떨어지고(떨어질 자리에 상자 그림자가 내려올수록 진해짐, 상자 위에 무기 이름), 맨주먹으로 닿으면 그 무기를 든다. 다 쓰면 다시 맨주먹.
  - 방망이(15번): 팔을 옆으로 들어 크게 휘두른다(예전과 같음).
  - 망치(3번): 크게 들었다가 내려찍어 앞 둘레를 모두 날린다.
  - 다이너마이트(1번): 던지면 떨어질 자리에 빨간 테두리 원과 도화선이 타는 만큼 줄어드는 안쪽 원, 1.6초 뒤 폭발해 둘레를 모두 날린다.
  - 금괴(15초): 들고 있는 동안 덜 밀리고 느려진다. 묵직하게 휘두른다.
  - 화면 아래에 내 무기와 남은 횟수·시간, 다른 사람 머리 위에 든 무기 이름. 다른 사람의 공격도 모두의 화면에 보인다.
- PC는 마우스가 화면 가운데에 고정되고(조준점), 카메라가 오른쪽 어깨 너머에 붙고, 캐릭터가 카메라가 보는 쪽을 본다. 왼쪽 Alt를
  누르면 마우스가 나타나고(이때 클릭은 휘두르지 않음) 다시 누르면 고정된다. 모바일과 게임패드(PC에서도)는 원래 조작.
- 방망이 기준으로: 앞쪽 부채꼴(거리 5.5, 좌우 70도)에 있는 사람이 맞는다(서버는 통신 지연을 봐서 7까지 봐준다). 스매시 레전드처럼
  체력(100, 방망이 한 대 12, 맨주먹 8)이 줄수록 멀리 밀린다(무기마다 피해와 밀림 배수가 다르지만 모두 체력에 비례):
  - 날림은 때리는 사람의 연타로 정한다: 이어서 누르면(맨주먹이면 0.8초 안) 1·2·3, 3번째가 맞으면 날림. 앞 공격이 맞아야 이어지고, 헛치거나 쉬면 1부터. 3번째는 예비 동작이 보이게 조금 늦게 맞는다.
    여러 명에게 둘러싸여 1.5초 안에 3대를 맞으면 튕겨 나간다(협공 보호). 공격 자세는 전신: 주먹은 왼손 잽 → 오른손 스트레이트 →
    어퍼컷, 방망이·금괴는 포핸드 → 백핸드 → 한 바퀴 도는 마무리.
  - 맞으면 맞은 자리에 만화식 타격 효과선(약한 타격 흰색, 날림 금색, 협공 날림 빨간색)이 튀고, 맞은 사람과 때린 사람이 함께 잠깐 멈춘다.
    내가 맞으면 밀린 방향으로 카메라가 밀렸다 돌아온다. 날아가면 팔을 휘저으며 흰 꼬리를 남기고, 착지하면 먼지가 인다(홈런은 한 바퀴 넘게 돌며 날아간다).
  - 연타 1·2번째 타격: 0.06초 멈칫하고 하얗게 번쩍인 뒤 선 채로 1.2~2스터드 밀린다. 0.3초 뒤면 다시 휘두르거나
    비킬 수 있다.
  - 연타 3번째: 날아가 눕는다. 날림만 보면 첫 콤보(체력 64)는 약 4.3~5.4, 두 번째(체력 28)는 약 11.0(지붕 폭 15에서
    Studio 실측). 같은
    방향으로 세 대를 다 맞으면 약한 타격의 밀림이 더해져 첫 콤보에서도 지붕 가운데에서 떨어질 수 있다(지붕 15에서는 경계선).
    날린 뒤 0.9초는 안 맞는다.
  - 체력이 0이 되는 한 방(9번째) = 장외홈런: 무기마다 다른 끝내기 소리(방망이는 "딱!"), 맞은 자리에 "홈런!", 빛 꼬리를 남기며
    하늘 높이 날아가 1.1초 뒤 금색 타격 효과선으로 반짝("펑") 사라지고 관전석으로. 화면 위에 "A → B 홈런!"(떨어뜨리면 "A → B 하차") 알림. 홈런은 날아갈 때 만화식 슬라이드 휘슬도 난다.
  - 머리 위와 화면 아래에 체력 막대(30% 이하면 빨갛게 깜박임). 판마다 다시 100.
- 떨어지면 모래에 떨어져 누운 채 기차 뒤로 멀어지고, 1.6초 뒤 공중의 대기실(관전석)로 올라가 남은 사람을 관전한다. 떨어뜨린
  사람의 "KO"가 올라간다(맞힌 지 6초 안). 내가 떨어지면 화면 가운데에 "하차!"(그 순간 판이 끝나면 바로 결과가 덮음).
- 한 판: 대기 → 3초 카운트다운(가운데 기차부터 칸마다 흩어져 정지, 가운데에 큰 숫자) → "출발!" 난투(최대 3분) → "X 승리!"(시간이 다 되면 무승부) → 대기 → 다음 판.
  난투 중 화면 위에는 시간판(마지막 30초는 금색)과 양옆에 "탑승객 N"·"KO N". 처음 탄 판에는 왼쪽에 조작 안내 카드("탑승 안내")가
  카운트다운부터 난투 8초까지 떴다 사라진다(입력 방식에 맞춰: 클릭/때리기 버튼/R2).
- 화면 위 표시·안내·알림 글자는 한 글꼴(Montserrat Black)에 진갈색 테두리(차체에 칠한 영어 글씨는 장식이라 그대로). 로블록스의 한글 대체 글꼴은 굵기가 하나뿐이라 굵기가 하나뿐인
  글꼴에서는 한글만 가늘게 나와서 바꿨다. 화면 문구는 `Words` 한 곳에 모았다.
- 소리: 칙칙폭폭 루프, 무기마다 다른 휙(주먹·방망이·망치·금괴·던지기)과 맞는 소리(날림은 한 겹 더, 홈런은 무기별 끝내기),
  같은 소리가 반복되지 않게 높낮이를 조금씩 흔듦, 카운트다운 트라이앵글, 시작 기적, 승리 종과 관전석 환호, 대기·난투 서부
  음악(오른쪽 "음악 ON/OFF" 버튼으로 끔). 로블록스 기본 효과음(핑)과 신스 딩은 쓰지 않는다. 음원은 로블록스가 제공하는 라이선스 라이브러리(Pro Sound Effects, APM Music)를 로블록스
  안에서 쓴다. 조명: 늦은 오후 햇빛, 먼지 낀 대기, 약한 블룸·색 보정(프로젝트 파일의 Lighting).
- 혼자 시험(Studio 전용): Workspace 속성 `TrainBrawlSolo`를 켜면 샌드백 5개가 난투 중에 서 있는 발판 위를 돌아다니며
  참가자로 센다(때리지는 않음).
- 아직 없는 것: 기차 앞뒤 이동, 봇(때리는 AI), 칸 떨어져 나가기, 강타, 기상 선택지, 매달리기, 배경음과 효과 다듬기, 무기 둘째
  묶음(쇠지렛대·석탄 덩이·갈고리 등, 오너가 고름).

## 코드 규칙 (전역 규칙 `~/.claude/CLAUDE.md` 3번의 이 게임 구체 사항)

- 서버 부품끼리, 클라이언트 부품끼리는 require하지 않는다. 연결은 `Main.server`와 `init.client`가 콜백으로 한다.
  공용 코드(`src/shared`)는 공용 코드만 require한다. 기준은 `tools/tests/check_deps.py`의 `ALLOWED` 표.
- require는 `require(<경로>:WaitForChild("이름"))` 꼴로만 쓴다(의존 검사가 읽을 수 있게).
- 조정할 숫자는 `src/shared/Config.luau`, 이름은 `src/shared/Names.luau`에 둔다.
- 서버가 판정하고(휘두르기 쿨다운·거리·각도·한 번에 한 번, 체력·타격 종류, 떨어짐, 탈락), 플레이어 캐릭터를 움직이는 일(밀림,
  날아가기, 떨어진 뒤 밀려나기)은 그 플레이어의 기기가 한다(캐릭터 물리는 그 기기 담당). 샌드백은 서버가 물리를 맡는다.

## 검사 명령

- `python -I tools/tests/run_tests.py` — 기차 배치·판자·시작 자리·탈락선·점프로 틈 못 건넘(실측 보정)·휘두르기 판정·날려 보내기·타격 규칙·
  조정값 약속·꾸미기(굴뚝 발판, 홈런이 협곡에 안 닿음, 모래 범위) 테스트(luau CLI, 실제 Config 수치) + 의존 방향 검사
- `python -I tools/lint/run_lint.py` — luau-lsp(Roblox API 타입) + selene. luau-lsp·selene·rojo가 PATH에 있어야 한다
  (이 PC: `~/.local/bin`). Roblox 타입 정의는 `.lint/`에 캐시된다(내려받기가 막히면 `Western train/.lint/`의 파일을 복사).
- Studio 확인: `rojo build default.project.json -o .qa/<이름>.rbxlx`로 만든 장소를 새 Studio 창에서 열고, 혼자면 Edit에서
  Workspace 속성 `TrainBrawlSolo`를 켠 뒤 Play(다시 빌드하면 속성이 빠지므로 다시 켠다).

`tools/lint/run_lint.py`와 `tools/tests/check_deps.py`는 `Western train/tools/`(원래 `Banned words/tools/`)에서 복사한 것이다
(세 번째 복사본 — 공용 도구 폴더로 합칠지는 오너와 시점을 정한다).
