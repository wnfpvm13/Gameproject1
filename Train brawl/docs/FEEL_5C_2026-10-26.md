# 5c 타격감과 날림 연출 — 만든 기록 (2026-10-26)

5단계(손맛·첫인상)의 세 번째 묶음. 묶음표는 `docs/FEEL_5A_2026-10-26.md` 첫 표. 방향 계획 3절 ②(양쪽 멈칫·충격 이펙트·방향 카메라 킥·소리 높낮이)와
⑦(날림 회전·꼬리·착지 먼지)을 만들었다. 소리 높낮이 흔들기는 5a에서 했다.

## 1. 무엇이 어색했고 어떻게 고쳤나

| 보이던 것 | 왜 어색한가 | 고친 것 |
|---|---|---|
| 맞은 사람만 0.06초 멈칫, 때린 사람은 그대로 | 맞은 감이 한쪽에만 있음 | 맞는 종류마다 멈칫이 다르고(약한 타격 0.06, 날림 0.1, 홈런 0.16초 — `Config.Feedback.HitStop`), 때린 사람의 공격 자세도 같은 시간만큼 멈춘다(`SwingPose.hold`) |
| 맞는 순간 흰 번쩍임뿐 | 맞았다는 표시가 약함 | 맞은 자리(맞은 사람 몸에서 때린 사람 쪽, 가슴 높이)에 만화식 타격 효과선(`ImpactBurst`): 가운데 원과 길고 짧은 직선 빛줄기가 튀어나왔다 0.18초에 사라짐. 약한 타격은 작고 흰색, 날림·홈런은 크고 금색, **협공으로 날아가면 빨간색**(5b 검토의 "협공 날림이 연타 날림과 같아 보임"). 그때마다 조금씩 돌아가고 빛줄기 길이·각도가 달라 같은 그림이 찍히지 않음 |
| 화면 흔들림이 방향 없는 랜덤 떨림 | 어디서 맞았는지 모름, 손맛이 없음 | 카메라 킥(`HitFeedback`): 내가 맞으면 밀린 방향으로 카메라가 빠르게 밀렸다 돌아옴(약한 타격 0.35, 날림 0.8, 홈런 1.1스터드), 날림·홈런은 시야가 7도 좁아졌다 돌아옴. 내가 때리면 맞힌 쪽으로 0.15스터드 |
| 연타 마무리의 휙이 1·2번째와 같음 | 큰 한 방이 귀로 안 들림 | 마무리는 같은 휙을 0.8배 속도(낮고 길게)로 |
| 날림은 뻣뻣하게 날아가 그대로 착지 | "날아갔다"는 느낌이 약함 | 날아가는 동안 팔을 휘젓고(5b), 짧은 흰 꼬리, 땅에 닿으면 모래색 먼지(`LaunchShow`). 홈런은 밀린 방향으로 한 바퀴 넘게 돈다(`Config.Knock.SpinTurns`, 비행 시간에서 회전 속도를 정하고 내려올 때 멈춤). 보통 날림의 공중제비는 검토 뒤 뺐다 — 4절 |

## 2. 코드

- 새 클라이언트 부품: `ImpactBurst`(타격 효과선, 프레임으로 그림 — 올린 이미지 없음), `LaunchShow`(날림 꼬리·착지 먼지).
- 바뀜: `Config.Feedback`(`HitStop` 종류별, `BurstSeconds`, `KickSeconds`, `KickStuds`, `FovPunch`, `DustSeconds`; 옛 `HitStopSeconds`·`ShakeSeconds`·
  `ShakeStuds` 대신), `Config.Knock.SpinTurns`, `BodyMotion.launch`(종류를 받아 멈칫 길이, 홈런 회전; `getUp`이 회전을 멈춤), `KnockFlight`·`Sandbags`(종류를 넘김),
  `HitFeedback`(카메라 킥·시야, 마무리 휙, 보여 줬는지 돌려줌), `SoundBank.play`(속도), `HitRules`·`FighterHealth`·`WeaponService`(협공으로 날렸는지를
  모든 화면에 — 맞음 리모트 6번째 값), `SwingPose.hold`, `OwnSwing`(맞힘 보여 줄 때 마무리인지 넘김), `init.client`(효과선·멈칫·날림 연출 연결).
- 테스트: 홈런 높이·모래까지 시간 검사가 홈런 멈칫(0.16초)을 빼고 계산, 멈칫 순서 검사, 협공 표시(세 사람 협공은 표시, 공격자 자신의 날림은 표시 안 함).
  145개 통과, 의존 검사 53모듈, 린트 새 지적 없음.

## 3. Studio 확인 (QA 창, 혼자 시험)

- 실제 클릭 세 번으로 샌드백을 때림: 효과선 3번(약한 타격·약한 타격·날림), 체력 100 → 76, 오류 없음(콘솔).
- 효과선 모양: 시험용 사본에서만 길이를 10초로 늘려 세 종류를 나란히 띄우고 실제 창(PrintWindow)으로 봤다. 처음 안(떨어진 둥근 가시)은 "해
  아이콘", 둘째 안(둥근 가시를 가운데에 붙임)은 "꽃잎"처럼 보여 버리고, 가는 직선 빛줄기로 바꿨다. (QA 캡처는 저장소 밖 작업 폴더에 있음.)
- 착지 먼지: 처음에는 나오지 않았다 — 누운 몸이 지붕에 조금 묻혀 몸 가운데에서 쏜 광선이 지붕 안에서 시작해 지붕을 못 봤다. 몸 위 2스터드에서
  쏘게 고친 뒤 날림 → 착지 순간 먼지가 생기는 것을 기록으로 확인(그 뒤 한 번 튀어 상자 위에 멈춤).
- 공중제비와 날림 거리(검토 뒤): 같은 R15 인형을 같은 힘으로 날리고 샌드백처럼 착지하면 일으켜 세운 뒤 쟀다. 체력 64 날림이 공중제비 없이 3.1, 1/4바퀴
  공중제비로 6.9스터드(등으로 떨어져 미끄러짐) — 지붕 가운데에서 끝까지 7.5에 가까워 누가 남느냐가 바뀌므로 보통 날림의 공중제비는 뺐다. 체력 28은
  17.3 대 16.9로 차이가 작았다. (이 방법은 2026-10-25 실측 4.3~5.4 / 11.0과 재는 방식이 달라 절대값은 비교하지 않고 공중제비 있고 없음만 비교.)
- 카메라 킥·시야 좁아짐·멈칫은 느낌이라 사람이 해 봐야 안다.

## 4. 남은 것

- 효과선은 맞은 자리에서 늘 맨 위에 그려진다(0.18초라 벽 너머로 보여도 짧음).
- 다른 사람 화면에서 날림 착지 먼지(몸이 뜬 뒤부터 세도록 고쳤지만 지연 환경 시험은 아직), 폰에서 효과선 크기와 성능 — 사람이 해 보고 정할 것.
- 효과선과 먼지 연기에 로블록스 기본 연기 텍스처를 씀(먼지만, 0.6초).
- 디버그 같은 원판·Sparkles·"✦" 별, 모바일 기본 버튼, 지붕 색 대비(5d).
