# 5d 디버그처럼 보이던 표시와 지붕 — 만든 기록 (2026-10-26)

5단계(손맛·첫인상)의 마지막 묶음. 묶음표는 `docs/FEEL_5A_2026-10-26.md` 첫 표. 방향 계획 3절 ⑤(원판·Sparkles 교체)와 ⑨(지붕 색 대비·속도감)를
만들었다. 홈런 끝의 "✦" 글자 별은 5c에서 금색 타격 효과선으로 이미 바꿨다.

## 1. 무엇이 어색했고 어떻게 고쳤나

| 보이던 것 | 왜 어색한가 | 고친 것 |
|---|---|---|
| 다이너마이트가 떨어질 자리에 반투명 빨간 Neon 원판 | 개발용 디버그 표시처럼 보임, 얼마나 남았는지 모름 | 빨간 테두리 원(폭발 넓이)과 그 안의 빨간 원이 도화선이 타는 만큼 줄어들어 0이 되면 터짐. 끝으로 갈수록 빨리 깜박임(초당 약 3번 → 12번). 서버는 보이지 않는 평평한 부품에 터지는 시각만 적고, 각 화면이 그 위에 그림(`GroundMarks`, SurfaceGui) |
| 상자가 떨어질 자리에 노란 Neon 원판 | 같은 디버그 느낌 | 상자의 그림자: 높이 있을 때는 작고 옅다가 내려올수록 커지고 진해짐 |
| 낙하산이 빨간 공 | 풍선이나 공처럼 보임 | 납작한 지붕 모양 덮개와 위의 밝은 통풍구, 덮개 가장자리에 매단 줄 네 개 |
| 다이너마이트 도화선의 2008년식 Sparkles(노란 별) | 오래된 기본 효과 | 작고 뜨거운 불꽃이 튀어 떨어지는 입자(`FuseSparks`), 손에 든 것과 던진 것 모두 |
| 지붕이 짙은 회색 | 넓고 비어 보이고, 검은 샌드백이나 어두운 아바타와 대비가 없음 | 녹슨 갈색(96, 70, 56)으로. 지붕 이음새·전망대 덮개도 같이 따라감 |
| 지붕 위에 서 있으면 기차가 서 있는 것 같음(배경만 흐름) | 달리는 기차 위라는 느낌이 약함 | 넓은 지붕 양쪽 가장자리에서 모래색 작은 알갱이가 달리는 속도의 약 두 배로 뒤로 날림(`WindDust`, 적고 옅게) |
| 모바일 "때리기"가 로블록스 기본 회색 원 버튼 | 기본값 그대로 | 게임의 판 모양(짙은 판, 나무색 테두리, 굵은 글자), 누르면 살짝 작아짐 |

## 2. 코드

- 새 shared `FuseSparks`(도화선 불꽃, 서버 부품 둘이 씀), 새 클라이언트 `GroundMarks`(바닥 경고 그림), `WindDust`(지붕 바람).
- 바뀜: `Dynamite`(Neon 원판 대신 보이지 않는 `BlastRing` 부품에 `EndsAt`·`Seconds`, 불꽃), `WeaponDrops`(낙하산 모양, 보이지 않는 `LandingMark`에
  `EndsAt`·`Seconds`), `WeaponGear`(불꽃), `Names`(바닥 표시 이름·속성), `SwingInput`(버튼 모양), `Config.Arena.Colors.Roof`, `init.client`(연결).
- 테스트·린트: 145개 통과, 의존 검사 56모듈, 린트 새 지적 없음(이번 묶음은 순수 계산이 없어 새 테스트는 없음).

## 3. Studio 확인 (QA 창, 혼자 시험)

- 화물칸 지붕 위에 서버에서 경고 부품 둘(다이너마이트 12초, 상자 12초 — 보려고 길게)을 놓고 실제 창으로 봤다: 빨간 테두리 원과 안쪽 원, 상자 그림자가
  지붕 위에 그려짐. 지붕은 녹슨 갈색이 되어 검은 옷 캐릭터가 또렷해짐. 처음엔 석탄차 위에서 시험해 경고가 기관실 지붕 아래에 가려졌다(다이너마이트가
  실제로 떨어지는 자리에 그리므로 게임에서는 문제없음).
- 떨어지는 상자를 카메라로 따라가 낙하산을 봤다: 공 대신 납작한 덮개와 줄. 통풍구가 덮개에 거의 묻혀 크기·높이를 키웠다(다시 보지는 않음).
- 못 본 것: 실제 다이너마이트를 던졌을 때 원이 줄어드는 움직임(부품을 직접 놓아 그림만 확인), 바람 알갱이가 실제로 눈에 띄는지(일부러 옅게 함),
  폰에서 버튼 모양(기기 시뮬레이터는 CAS 버튼을 그리지만 눌러 보지는 못함).

## 4. 남은 것

- 낙하산 덮개는 납작한 타원체라 아래쪽도 둥글게 보인다(움푹한 안쪽이 없음). 메시를 쓰려면 오너 업로드가 필요할 수 있다.
- 협곡이 층층이 쌓은 직사각 블록의 반복(점검 지적) — 지형(Terrain)으로 바꾸는 것은 큰 작업이라 따로.
- 승리·이모트 애니메이션, 이미지 글자, 무기·협곡 메시는 오너 자원이 필요(방향 계획 3절).
