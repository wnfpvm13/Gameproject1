# 5e 때리는 봇, 같은 몸, 맨주먹 가드와 동작 — 만든 기록 (2026-10-27)

5단계(손맛·첫인상) 뒤에 붙인 묶음. 오너 말:

- "게임의 캐릭터 몸체를 전부 R6으로 고정해서 싸우게 해야 모션이 더 괜찮아질까? 주먹질하는거나 무기가 떨어지는 속도 등이 느린 등.. 문제가
  많다고 봐. 전투모션을 더 고급지고 멋지게 수정해 그리고 AI들이 공격하지 않아"
- "서로 때리는 게임이니 피격부위인 몸통은 서로 같아야한다고 생각하거든?"
- 추천안을 고름: "추천대로 몸 통일하고 주먹 동작부터 다시 진행해"

정한 방향: R15 유지(팔꿈치·무릎·허리 관절, 레이어드 옷, 지금 자세 코드를 살림), 몸은 모두 같게, 순서는 봇 → 가드와 맨주먹 동작·속도 →
무기 자세 → 궤적·상자. 이 묶음은 앞의 둘이다(커밋 두 개: 봇+몸, 가드+맨주먹).

## 1. 무엇이 어색했고 어떻게 고쳤나

| 보이던 것 | 왜 어색한가 | 고친 것 |
|---|---|---|
| 혼자 시험하면 "AI"가 돌아다니기만 함 | 원래 맞기만 하는 샌드백이라 주고받는 손맛을 볼 수 없음 | 봇이 같은 칸의 가장 가까운 상대에게 달려가 마지막은 걸어 들어가고, 잠깐 반응한 뒤 1·2·3 연타(`BotBrain`, 순수 계산 `BotPlan`). 서버 판정은 사람과 같음(`WeaponService.attack`, 네트워크 여유만 없음) |
| 봇이 3.5~3.8 거리에서 멈춰 서서 안 때림 | 1스터드 남짓 걸으라는 `MoveTo`는 목표보다 약 1스터드 앞에서 "도착"으로 끝남 | 가까우면(때리는 거리 + 3 안) `Humanoid:Move`로 곧장 걸어 들어감(초속 6). 둘이 마주 와도 한 번 생각할 사이에 1.2만 가까워져 약 2에서 멈춤 |
| 아바타마다 키·체형·걷기 애니메이션이 다름 | 판정은 중심점끼리 재지만 중심 높이·발 높이·부딪힘·맞는 모습이 다르고, 애니메이션 팩(닌자·좀비)이 코드 자세를 휘게 함 | 겉모습이 다 실린 뒤 몸통·팔·다리를 기본 부위로, 크기 배율을 `Config.Body`로, 애니메이션을 기본으로(`AvatarRules`, `ApplyDescriptionAsync`). 머리·얼굴·옷·액세서리는 그대로. 봇도 같은 배율로 만듦 |
| 봇과 플레이어 키가 약 0.2 다름 | 새 `HumanoidDescription`의 기본값은 체형 0.3·비율 1이라, 기본 몸(0/0)보다 큼 | 봇도 `Config.Body` 배율로 만듦. Studio: 둘 다 허리 높이 2, 윗몸통 2×1.6×1, 같은 메시 |
| 주먹을 뻗고 나면 매번 팔을 내린 기본 자세로 풀렸다가 다시 나감 | 공격 자세가 "차렷"에서 시작해 차렷 쪽으로 끝남 | 맨주먹을 든 사람은 판이 시작을 세거나 싸우는 동안 서 있으면 복싱 가드(왼손 조금 앞, 오른손 턱 옆, 허리를 조금 돌림)를 올림. 0.15초에 올라오고 내려감, 빨리 달리면 60%까지 내려 팔이 조금 흔들림(`SwingPose` 자세 층, `AttackPoses.stance`) |
| 잽·스트레이트가 팔과 상체만 움직임 | 몸이 안 실려 가벼워 보임 | 가드에서 나가 가드로 돌아옴: 살짝 당김 → 골반·허리가 먼저 돌고 팔꿈치는 아직 굽음 → 맞는 순간 팔이 펴짐 → 아주 잠깐만 뻗은 채 → 반쯤 굽혀 빠르게 가드로. 스트레이트는 더 감았다 골반으로 밀어냄(뒷무릎 살짝) |
| 뻗은 끝에서 0.05초 넘게 멈춤 | 헛칠 때도 둔해 보임(맞으면 멈칫은 따로 있음) | 뻗은 채 있는 시간 0.22 → 0.06(동작 길이에 대한 몫) |
| 3타 어퍼컷이 한 걸음 0.5 앞으로 미끄러짐, 주먹이 제 얼굴 앞에서 올라감 | 발이 미끄러져 보이고 상대 턱에 안 닿아 보임 | 앞 이동 0.2, 맞는 순간 위팔은 앞으로·아래팔은 위로(턱 아래로 올려 침), 그 뒤 몸을 젖히며 계속 올라감 |
| 맞은 뒤 움찔이 팔을 내린 자세로 끝남 | 가드가 생기면 매번 팔이 툭 떨어짐 | 머리·어깨가 맞은 쪽으로 돌고 팔이 벌어졌다가 가드로 돌아옴 |
| 주먹질이 느림 | 다음 공격까지 빈 시간이 김 | 맨주먹 쿨다운 0.45 → 0.4, 동작 0.26 → 0.24(0.1초에 맞는 건 그대로). 맞은 경직 0.3 → 0.26(맞은 쪽이 맨주먹이나 방망이로 먼저 받아칠 수 있게: 경직 + 맞는 시간 < 맨주먹 쿨다운, 테스트), 서버가 맞은 직후 받아 주는 여유 0.25 → 0.22(경직보다 짧게), 연타 이음 0.35 → 0.4(맨주먹 누름 사이 0.8초 안 그대로) |

## 2. 코드

- 커밋 1(봇+몸, 3546781):
  - 새 서버 `BotBrain`(봇의 생각: 상대 고르기·다가가기·연타 계획), 새 shared `BotPlan`(순수: 가장 가까운 상대, 설 자리, 돌아다닐 자리),
    새 서버 `AvatarRules`(플레이어 몸 통일), `ArenaLayout.topUnder`(발 아래 칸).
  - `WeaponService`: 쿨다운·연타를 플레이어가 아니라 캐릭터(Model) 기준으로 (봇도 같은 규칙), `attack(model, facing)` 추가(서버가 직접 움직이는
    봇: 쿨다운·경직 여유 없음). 그래서 다시 태어난 캐릭터는 쿨다운·연타가 새로 시작한다(새 캐릭터는 다음 판에만 싸움).
  - `Sandbags`(봇의 몸): 생각은 `Main`이 이어 줌, 약한 타격에 경직 동안 멈춤, 걸음 멈출 때 `Move`도 멈춤, `Config.Body` 배율로 만듦.
  - `Config.Sandbag`(봇 수치), `Config.Body`(몸 배율), `Words.bot`("봇 N").
- 커밋 2(가드+맨주먹):
  - `AttackPoses`: `stance(style)`(맨주먹만 가드, 무기는 아직 없음), 맨주먹 세 동작을 가드 기준으로 다시 씀(`fromGuard`), `react`가 자세를 받아
    거기로 돌아옴.
  - `SwingPose`: `follow()`한 캐릭터마다 자세 층. 매 프레임 `Stepped`에서 애니메이션 위에 자세를 먼저 쓰고, 공격·움찔 그림은 그것을 바탕으로 섞음.
    `PreAnimation`에서 자세가 쓴 관절도 곧게 펴 둠(다음 애니메이션 단계가 덮어쓸 수 있게). 몸 부위가 바뀌면 관절을 다시 찾음.
  - `Config`: 맨주먹·경직·연타 이음 수치.
- 검토 뒤 고침(커밋 3):
  - `AvatarRules`가 몸을 바꾼 캐릭터에 `Names.BodyReady`를 달고, `RoundService`는 그런 플레이어만 판에 넣는다(늦게 실린 원래 몸으로 싸우지
    않게). 겉모습이 끝내 안 실리면 `Main`이 10초 뒤 그대로 맞춰 준다(못 들어가는 일이 없게). 바꾸기에 실패해도 경고만 하고 표시는 단다.
  - `SwingPose`: 자세의 관절을 자세가 쓰는 관절 하나하나로 확인해 다시 찾음(팔만 바뀌거나 늦게 와도), 날아가거나 자세 없는 무기를 들면 자세가
    바로 사라짐(다른 그림이 안 쓰는 팔꿈치가 굽은 채 남지 않게), 관절 돌려주기 반복을 한 곳으로.
  - `BotBrain`: 탈락한 봇의 목표는 세지 않음, 상대가 사라지면 걸어 들어가던 걸음을 멈춤. `Sandbags`: 싸움이 끝나면 걸음을 멈춤(결과 화면 동안
    기차 밖으로 걸어가지 않게).
  - `AttackPoses`: 스트레이트가 오른무릎을 잡지 않음(걸으며 칠 때 다리가 굳지 않게).
  - 경직 0.26, 받아 주는 여유 0.22(위 표).
- 테스트·린트: 169개 통과(봇 계산, 몸 배율, 가드 시작·끝, 잽이 펴졌다 돌아옴, 움찔이 가드로, 맨주먹·방망이로 먼저 받아침, 서버 경직 검사가
  남음), 의존 검사 59모듈, 린트 새 지적 없음.

## 3. Studio 확인 (QA 창, 혼자 시험)

- 몸: 플레이어(오너 아바타)에 적용 뒤 `GetAppliedDescription`이 몸 부위 0·배율 1/1/1/1/0/0·애니메이션 0, 봇과 부위 크기·메시가 같음.
- 봇: 같은 화물칸에 둘을 14 떨어뜨려 놓으니 6~7.5초 동안 서로 4~6번 때려 체력 100 → 44~60(두 번 시험). 거리는 대개 3~5.
- 가드: 클라이언트에서 플레이어·봇 다섯 모두 관절 값이 가드 값과 같음(왼팔꿈치 105, 오른팔꿈치 128, 허리 -10).
- 동작: 게임 카메라가 장면 찍기 카메라를 덮어써서, 높이 300에 애니메이터 없는 기본 몸 둘을 3.2 떨어뜨려 세우고 동작을 프레임별로 찍었다
  (가드, 잽이 닿는 순간, 스트레이트 + 맞은 쪽 움찔, 어퍼컷이 닿는 순간). 어퍼컷은 처음에 주먹이 제 얼굴 앞에서 올라가 고쳤다.
- 못 본 것: 실제 속도로 움직이는 모습(장면 찍기는 정지 화면만), 사람끼리 핑을 두고 받아치기, 폰.

## 5. 남은 것

- 무기 자세(방망이 어깨에 걸침, 망치 두 손 낮게 등)와 무기 동작 다듬기(방망이 마무리 한 바퀴 회전 → 크게 휘두르고 끝나는 동작), 휘두름 궤적,
  상자 낙하(예고 그림자 먼저, 낙하는 짧고 빠르게, 각 화면이 그림).
- 봇: 칸 건너기, 무기 줍기(B단계).
- 머리는 그대로라 아주 큰 머리나 헤드리스는 그대로 보인다. 충돌은 게시 때 Avatar Settings의 단일 충돌 상자로 같아진다.
- 게시할 때 Avatar Settings(R15만, Consistent Gameplay, 액세서리·옷 한도) — 스크립트로는 못 바꿈.
