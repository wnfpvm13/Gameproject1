오너 요청: "주먹으로 상대를 때려야만 2타 3타로 가던데 그냥 허공만 때려도 2타 3타 넘어가게 해줘", "무기같은 걸 만들 때 연결되어있는 meshy를

## 1. 조사 (타격감 기법, 하위 에이전트가 웹에서 모음)

실제 측정값이 있는 출처는 셋이다.

- Capcom 벨트스크롤 프레임 측정: The Punisher의 멈춤(때린 쪽/맞은 쪽)은 잽 6/8, 크로스 8/10, 마무리 9/11프레임이다
  (https://shane-sicienski.com/blog/blog-post-title-one-55pmn).
- Smash 위키의 히트래그·넉백 공식(https://ssbwiki.com/Hitlag, https://www.ssbwiki.com/Knockback).
- Roblox 카메라 흔들림 모듈 EZ Camera Shake(https://github.com/Sleitnick/RbxCameraShaker).

그 밖의 근거는 이렇다.

- Sakurai 칼럼 번역: 맞은 쪽을 크게, 때린 쪽은 약하게 흔든다. 땅에서는 옆으로 흔들고, 흔들림은 줄여 간다
  (https://sourcegaming.info/2015/11/11/thoughts-on-hitstop-sakurais-famitsu-column-vol-490-1/).
- 히트스톱 가이드: 가벼운 타격 2~4, 무거운 타격 6~10, 필살 12~18프레임이다. 번쩍임은 1~2프레임만 강하게 준다(https://gamineai.com/...,
  https://swordarcade.xyz/guides/game-feel-hitstop-and-screen-shake/).
- 카메라 흔들림은 0.2~0.3초 안에 끝낸다. 굴림(roll)이 멀미를 가장 부른다(디자이너 블로그, 연구 아님).
- 경험칙: 공격마다 1.5~2.5, 마지막 타격은 3~4 내딛는다. 헛스윙에도 내딛기·휙 소리·궤적은 주고, 멈칫·번쩍임·타격음은 맞았을 때만 낸다.
- Battlegrounds류의 M1 연타: 마지막 타가 날린다. 마지막 입력 약 1초 뒤 초기화한다. 헛스윙에도 넘어가는지는 출처를 찾지 못했다.

지금 값 중 그대로 둔 것은 둘이다.

- 멈칫 0.06 / 0.1 / 0.16초(약 4 / 6 / 10프레임)는 범위 안이라 그대로 둔다.
- 날림을 빠르게 떴다가 강하게 감속하는 곡선으로 바꾸는 것은 5e 3부에서 잰 날림 거리를 다시 바꾸게 되어 다음으로 미뤘다.

## 2. 한 일

| 무엇 | 어떻게 |
|---|---|
| 허공 연타 | `AttackString`: 연타 상태에서 `landed`를 없앴다. 무기가 다시 준비된 뒤 `StringGap` 안이면 맞든 헛치든 다음 단계, 3번째 뒤나 쉬면 1. 서버도 같은 규칙으로 화면이 그린 단계를 받는다(다음 단계만, 여유 0.15초). `OwnSwing`·`WeaponService`·`init`에서 `landed` 호출을 뺐다 |
| 내딛기 | `BodyMotion.lunge`(공유): 조준 방향으로 `LinearVelocity`(선 모드) 0.1초. 앞을 구(반지름 1)로 훑어 무엇이든 0.4 앞에서 멈추고, 내디딘 자리 0.5 앞 발밑을 0.5씩 줄여 가며 확인해 디딜 곳이 있는 데까지만 간다(`room`). 공중·고정·눕힘이면 없음. 맞으면(`newHit`) 끊김. 거리 규칙은 `WeaponRules.lunge`(1·2번째 1.5, 3번째 3, 망치 1, 던지기 0). 플레이어는 `OwnSwing`의 `lunge` 훅(`init`이 연결), 봇은 `Main`이 `weapons.attack`을 감싸 내딛고, `BotBrain`은 내디딘 자리에 선다(뒤로 걸어 돌아가지 않게) |
| 맞은 사람 떨림 | `AttackPoses.shaken`(순수): 멈칫 시간 동안 루트 관절을 밀린 방향(몸 기준)으로 `Config.Feedback.Shake`만큼, 1/60초마다 방향을 바꾸며 선형으로 줄임. `SwingPose.react`가 감싼다. 관절만 움직여 몸(물리)은 그대로 |
| 때린 사람 멈칫 | `Config.Feedback.AttackerHold` 0.04 / 0.07 / 0.13(맞은 사람 0.06 / 0.1 / 0.16보다 약 2프레임 짧게). `init`의 예측과 서버 알림 둘 다 |
| 번쩍임 | `HitFeedback.flash`: 하이라이트를 완전히 흰색(`FillTransparency` 0)으로 0.03초, 0.08초에 사라짐 |
| 궤적 | `SwingTrail`(새 클라이언트 모듈): 공격마다 Trail 하나를 만들어 타격 구간(맞는 순간까지의 45% 지점 ~ 맞은 뒤 0.06초)에만 켬. 맨주먹은 치는 손(`AttackPoses.hand`: 1번째 왼손, 나머지 오른손) 양옆 0.3에 붙인 점 둘(카메라를 향함), 무기는 `WeaponGear`가 무기에 만든 `TrailTip`·`TrailBase` 사이(방망이 끝 2스터드, 망치 머리, 금괴 길이; 다이너마이트 없음). 3번째는 금색, 나머지는 흰색. 내 공격은 누를 때, 남의 공격은 `SwingAt`을 받을 때(`follow`의 `heard`가 시작 시각을 넘김) |
| 날림 고리 | `ImpactBurst`: 날림·협공 날림 효과선이 효과선 색 고리를 0.3초 동안 2.4배까지 퍼뜨리고 사라짐. 선 굵기는 보는 거리에서 0.22스터드가 되게 픽셀로 바꿈 |
| 내 날림 카메라 | `HitFeedback.dealt`: 내가 날림을 맞히면 킥 0.45(약한 타격 0.15)와 시야 3° 좁힘 |
| 테스트 도구 | `tools/tests/run_tests.py`의 가짜 `Vector3`에 `+`, `-`, `*`, `==`를 더함(`shaken` 테스트) |

## 3. 확인

- 테스트 187개 통과. 새로 넣은 검사는 다음과 같다.
  - 허공에도 1·2·3, 내딛기 규칙.
  - 내딛기가 맨주먹 타격 전에 끝남.
  - 치는 손.
  - 모든 타격 종류에서 때린 사람이 먼저 풀리고 맞은 사람이 떨림.
  - 번쩍임 길이, 내 날림 킥 크기.
  - 떨림의 방향, 프레임마다 뒤집힘과 감쇠, 멈칫 뒤 없음, 받은 자세를 안 바꿈, 옆에서 맞으면 옆으로.
- 의존 검사 61모듈, 린트 새 지적 없음.
- Studio(QA3, 혼자 연습, 2026-10-28):
  - 허공에 세 번 누르니 서버 단계 1·2·3.
  - 맨주먹 궤적은 누르고 0.05초 뒤 켜져 0.16초에 꺼짐(3번째 0.08~0.25초).
  - 내딛기 실측은 지붕 가운데에서 1.5 → 1.8, 3 → 3.4였다. 멈춘 뒤 조금 더 간다.
  - 지붕 끝(7.75) 1 앞에서는 0, 0.6 앞에서 3을 눌러도 0이었다. 2.5 앞에서 3을 누르면 1.5만 가서 끝까지 0.7 남았고, 계속 지붕 위에 서 있었다.
  - 봇 앞에서 친 프레임을 찍어 보니 방망이 흰 궤적, 3번째 금색 궤적, 금색 효과선과 퍼지는 고리가 보였다.
  - 콘솔 오류 없음.
- 못 본 것:
  - 화면에서의 맞은 사람 떨림과 번쩍임(단위 테스트만).
  - 봇이 내디딘 뒤 뒤로 걷지 않는지: 확인 도중 플레이가 밖에서 멈춰 다시 켜지 않음.
  - 사람끼리 핑을 두고(내딛기 뒤 서버 판정 거리; 서버 여유 1.5 안으로 봄).
  - 폰.
