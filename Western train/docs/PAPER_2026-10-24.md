# 철퍽 때 종이처럼 납작: 만든 기록 (2026-10-24)

## 무엇을 만들었나

오너의 "다음 단계 하나씩 작업 시작해"의 마지막 차례(결정 13 순서)인 "철퍽 때 종이처럼 납작"을 만들었다.
- 다리에 철퍽 맞으면(공중에 있었거나, 납작하지 않은 지붕에 서 있었을 때) 카우보이가 다리 쪽(앞)을 보고 앞뒤로 종이처럼 얇아진다
  (두께 0.12배, 0.06초 만에).
- 0.35초 동안 다리 앞면에 붙어 다리와 같이 뒤로 끌려간다(달리기 속도).
- 그다음 떨어져 나와 종이처럼 떨어진다: 초당 5로 내려가며 좌우로 ±1.2 흔들리고 흔들림에 맞춰 제 평면 안에서 0.35라디안
  기울고, 세로축으로 초당 1.1바퀴 돌아 얇은 옆면이 보이고, 달리기 속도의 0.35배로 뒤로 밀린다. 지붕 위에서는 지붕에 얹힌 높이
  아래로 내려가지 않는다(다시 솟는 지붕에 묻히지 않게).
- 1.2초 뒤(예전과 같은 시간) 마지막 칸으로 돌아오면 "뽀용" 하고 원래보다 30% 두껍게 부풀었다가 0.2초 만에 제 두께로 돌아온다.
- 운전사 얼굴 창에도 "철퍽!"이 뜬다.
- 통에 맞는 "쿵!"과 떨어지는 "앗!"은 예전 그대로다.

| 모듈 | 바뀐 것 |
|---|---|
| `shared/PaperPath`(새) | 순수 수학: `thickness(t)`(두께 배율), `at(t, speed)`(철퍽 지점에서의 위치 x·y·z와 방향 yaw·tilt) |
| `shared/Config`, `shared/Names` | `Config.Paper`(두께·시간·떨어지는 속도·흔들림·회전·밀림·뽀용), `Config.Cowboy.KnockBack` 주석(이제 통 전용); `SplatRemote`·`SplatAt` |
| `server/SplatService`(새) | `Splat` 리모트: 그 기차의 카우보이가 보낸 철퍽 시각을 지연 허용(0.35초) 안으로 맞춰 `SplatAt`으로 씀(1.2초에서 지연 허용을 뺀 간격에 한 번) |
| `server/Main`, `server/Net` | `SplatService` 연결(카우보이 → 그 기차), `Splat` 리모트 |
| `client/CowboyRules` | 다리 철퍽 → `splat`: PlatformStand, 그때 위치·달리기 속도 기억, 매 프레임 `PaperPath.at`대로 루트를 직접 놓음(앞을 보게, 속도 0, 지붕 위에서는 지붕에 얹힌 높이 아래로 안 감), 1.2초 뒤 마지막 칸. 돌아갈 지붕을 못 찾아도 PlatformStand는 풂 |
| `client/PaperPose`(새) | 캐릭터의 보이는 부품(루트 빼고)을 각자 앞뒤 축으로 얇게, FileMesh 액세서리는 Scale로, 얇은 동안 충돌 끔, 얇은 동안 새로 붙은 부품도 포함. 1이 되면 원래 크기·충돌로 정확히 되돌림. 매 프레임 `flush()`가 이번 프레임에 안 그려진 캐릭터(기차가 없어짐, 카우보이가 바뀜)를 되돌림. 모든 클라이언트가 모든 카우보이에 대해 그림(로컬) |
| `client/init` | 철퍽 → `Splat` 리모트(철퍽 시각) + 바로 그림, 다른 기차는 `SplatAt`을 따라 그림(운전사면 "철퍽!"). 철퍽은 그때의 캐릭터에만: 기차마다 카우보이 캐릭터가 언제부터 그 캐릭터였는지 기억해, 철퍽 시각보다 나중에 나타난 캐릭터(리스폰, 다른 카우보이)는 그리지 않음. 매 프레임 `PaperPose.set` 뒤 `flush`, 종이 비행 중에는 엎드리기 안 함 |
| `tools/tests` | 10개(두께: 전·후 그대로, 바로 얇아짐, 이어짐, 뽀용; 비행: 붙어 끌려감, 떨어져 나오는 곳이 이어짐, 흔들림 안에서 내려감, 다리보다 느리게 밀림, 옆면이 보이게 돎, 돌아오기 전에 땅에 안 닿음) → 124개 |

## 교차검증 (Codex + Claude 검토자, 1회씩)

- Codex: P2 4건 — (1) 철퍽 중 기차 추적이 끝나거나 카우보이가 바뀌면 캐릭터가 얇은 채로 남음, (2) 부품을 한 번만 모아 얇아진 뒤
  붙은 액세서리는 보통 두께·잠깐 떨어진 부품은 복원 안 됨, (3) 충돌하는 몸통 크기를 바꿔 내 캐릭터 물리에 끼어듦, (4) 철퍽이 기차에만
  묶여 리스폰한 새 캐릭터·다른 카우보이도 얇아짐. P3 1건(문서의 기울기 표현).
- Claude 검토자: P1·P2 없음, P3 7건 — 뽀용 0.2초 동안 엎드리기 막힘, 떨어지는 종이가 다시 솟는 지붕에 묻힘, 다른 화면의 시점 차이,
  서버 횟수 제한이 늦은 신고에 불리, 액세서리 방향·얼굴 부착물 겉모습, (기존) 돌아갈 지붕이 없으면 PlatformStand가 안 풀림, 주석·문서.
- 고친 것: `PaperPose.flush()`(이번 프레임에 안 그려진 캐릭터는 되돌림), 얇은 동안 새 부품도 포함·떨어진 부품도 복원, 얇은 동안 충돌
  끔, 철퍽을 그때의 캐릭터에만(아래 재확인 뒤 보강), 엎드리기는 비행 중에만 막음, 비행이 지붕 아래로 안 내려감, `putBack`이 늘
  PlatformStand를 풂, 서버 횟수 제한에 지연 허용만큼 여유, 주석·문서.
- 넘긴 것: 액세서리 방향·얼굴 부착물의 겉모습(크기는 정확히 돌아옴), 다른 화면의 시점 차이(두 클라이언트 시험 항목), 카우보이가

## 두 클라이언트 시험 (통·점프·금화·종이, 2026-10-24)

Studio "서버 및 클라이언트" + 클라이언트 2개(Player1 운전사, Player2 카우보이, 혼자 시험 속성 끔)로 이번 네 단계를 같이 봤다.
- 운전사가 Space → 카우보이 화면에서 기차가 5.02만큼 뜨고 꼭대기 고리가 뜸. 서버 `JumpAt`은 운전사가 누른 시각(받은 시각보다
  0.03초 앞).
- 운전사가 S를 누른 채 다리 1을 지나는 동안 카우보이를 공중에 두자 철퍽: 카우보이 화면 두께 0.12 → 1.00, **운전사 화면에서도
  카우보이가 0.12로 얇아지고 "철퍽!"이 0.05초 뒤에 뜸**, 서버 `SplatAt` = 카우보이의 철퍽 시각. 운전사 화면에 "통과!".
- 운전사 화면에도 금화 크레인·점프 표시, 굴러오는 통, 급수탑이 그려짐(카우보이가 있는 기차).
- 못 한 것: 실제 운전사와 같이 뛰어 금화 줍기. 두 번째 세션에서 키 입력 도구의 입력이 클라이언트에 전혀 전달되지 않아(첫 세션에서는
  됐음, 창을 앞으로 가져와도 안 됨) 운전사가 다리를 납작하게 지날 수 없었다. 같이 뛰기 금화는 혼자 시험 모드(봇 운전)에서 확인했고,
  점프 시각이 누른 시각으로 찍히는 것은 위에서 확인했다.
